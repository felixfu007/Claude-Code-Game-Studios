# Story 003:卡池、手牌與棄牌

> **Epic**:技能卡牌系統 —— 邏輯層
> **型別**:Logic(**BLOCKING**;AC-10 為 UI 型 ADVISORY,本 story 只做它的邏輯半)
> **狀態**:📋 Ready
> **估時**:M
> **依賴**:無

## 目標

卡池、手牌、已用區三個位置,以及牌在它們之間的移動規則。

## 規則(來源:GDD Core Rules 二 + States and Transitions ①)

| 規則 | 值 |
|---|---|
| 開局手牌 | **5 張** |
| 補牌 | **每回合開始補 1 張** |
| 手牌上限 | **5 張**。滿手時**仍補牌**,然後**強制玩家棄一張** |
| 棄哪一張 | **可棄新抽的、也可棄原本手上的 —— 選擇權在玩家,系統不代為決定** |
| 每回合出牌數 | **不限** |
| 戰鬥結束 | 未打完的牌全部收回,退回卡池,不帶到下一場 |

**一張牌的位置**:`卡池 → 手牌 →(打出|棄掉)→ 本場已用區 →(戰鬥結束)→ 卡池`

🔴 **「已用區」不是多餘的中繼站,拿掉它會壞掉兩件事之一**:
- **打出後立即退回卡池** → 同場可重複抽到同一張,**公式四「卡池 > 11 就不會重複」在數學上失效**
  (不是機率降低,是保證消失)
- **打出後永遠離開卡池** → 卡池單調萎縮,牴觸「牌永不銷毀」

**已用區是唯一同時滿足那四處既有承諾的讀法,且不新增任何玩家可見的概念。**

🔴 **「戰鬥結束收回」是繼承義務 2 的滿足手段,不可省略。**
它防的是玩家囤牌到戰役尾聲一次打出以規避時近性衰減:囤積 K 張一次打出的讀值放大倍數
≈ `Σ λʲ`,在 λ∈[0.90,0.98]、K=5 下約 **4.1~4.8 倍**。**手牌能囤幾張,放大倍數就大約是幾倍。**
戰鬥結束收回把囤積限制在單場內,**跨戰役囤積在物理上不可能。**

## 🔴 隨機的界線

**隨機只發生在一個地方:這次補牌從卡池裡抽到哪一張。**
牌一進手,它的全部內容(效果類別、幅度、可作用對象)**完全確定、公開、可推算。**
**結算路徑零 RNG**(專案級禁令 `rng_in_combat_settlement`)。

⚠️ **抽牌的隨機源必須可注入且可固定種子** —— 否則測試不可能是決定性的,
而 `.claude/docs/coding-standards.md` 明訂「Tests must produce the same result every run」。
**不得在卡池類別內部直接呼叫全域 RNG。**

## 補測(GDD 登記為零 AC 覆蓋)

- **卡池張數少於開局手牌數** → 開局發不滿 5 張,**合法且不報錯**(牌不足就是牌不足)
- **每回合出牌數不限** → 同一回合連打 3 張,第 3 張不被拒絕
- **卡池抽空結構上不會發生** → 反覆抽到池空後補牌,斷言不崩潰且總量仍恆定
  ⚠️ **這條是不變量測試,不是自然成立的** —— GDD 明文「若實作讓牌消失,此保證即失效」
