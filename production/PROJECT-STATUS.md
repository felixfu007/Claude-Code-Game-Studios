## 你今天決定了什麼(18 項,挑重要的講)

### 這是什麼樣的遊戲

- **戰鬥完全可預判、零骰子。** 精算的爽感一點都不減。但你精算的對象從「打贏敵人」
  變成「在資源不夠的情況下維持十段關係」
- 五大支柱**一根都沒動**

### 人跟人之間有兩件事在跑

| | 這是什麼 | 誰在推 | 決定什麼 |
|---|---|---|---|
| **關係** | 親近 ←→ 對立 | 合作卡、競爭卡 | **打起來順不順** |
| **腐蝕** | 祂在這個人心裡站穩了多少 | **只有低語卡** | **結局** |

**對立不是壞事**——只是另一種工作方式。**腐蝕不可修復**,你的原話是
「就像人與人心中的芥蒂,永遠無法抹除」。

### 結局怎麼判

**兩段式:先看腐蝕,再看關係。**

1. **腐蝕達標 → 壞結局。關係完全不看。**(你讓祂進來了,其他什麼都不算數)
2. 腐蝕沒達標 → 看關係**偏向哪一邊** → **合作結局** 或 **競爭結局**

**兩個乾淨結局都是五個人全部活著回去,沒有人犧牲。** 差別在之後:
合作的人得到彼此,競爭的人得到自由。

### 死亡與重來

**沒有永久角色死亡。** 任何角色倒下 = 這一關失敗 = 回到上一次營火重來,
**好感度、腐蝕、牌組全部一起回滾**,而且**連營火都可以重做**。

**營火就是存檔點。** 手動存檔只能在營火、覆寫同一份進度——**它是「現在離開遊戲」的入口,
不是時光機。** 這樣腐蝕才是真的回不去。

### 這個世界是什麼

- **祂要的不是力量。** 力量對祂不稀有,**有趣才稀有**。咒印是甜點,主餐是看五個人互相撕咬
- **從頭到尾都是奈亞在搞鬼。** 森林是祂、五個人是被帶進去的、
  中期五關的怪物**就是那個角色的心魔**
- 所以**低語卡就是祂造怪物的方法**——這是把玩法和故事接起來的那根釘子

## 你接下來要決定的

### 🔴 一件事,但它其實是三件事綁在一起

你說「壞結局的腐蝕門檻很低」。這帶來一個體驗問題:

> 門檻低 → 玩家可能**第四關就跨線**。而規則要求跨線當下必須告訴他「有一條路關上了」。
>
> **結果是他還要再打六關,全程知道自己已經完蛋。那是很長的一段死路,他會直接重開。**

而**「腐蝕達標」是誰達標**(任何一人 / 五人總量 / 咒印角色)**你還沒決定**,
門檻越低,這個選擇的影響越大。

**我沒有一次問你一題,因為那會逼你在看不到全貌的情況下答。**
**已經送給敘事總監,請它給你一個三件事一起考慮過的建議。**

### 🟡 結局輪廓能不能落檔

三個結局的完整輪廓已經寫好,敘事總監第一輪判「需修正後落檔」,
修正已完成,**第二輪正在跑**。

## 今天做對的一件事,我想特別講

**你主動問「這個專案有編劇的專業 Agent 嗎」。**

有。而且有三個:**敘事總監**(故事結構)、**編劇**(台詞)、**世界觀建構**(世界規則)。

**而我在你問之前,已經自己寫了整套世界觀骨架和三個結局的輪廓。**
那不是我的專業範圍。**你問的那一句,把它送回了對的人手上。**

**敘事總監第一輪就抓到一段我寫的、會反咬你整個設計的文字**——
我把最差結局寫成了「唯一一次角色真的贏了祂」,那會讓玩家**想去追壞結局**,
剛好抵消掉你三項裁決建立起來的嚇阻力。**我當下完全沒看出來,已經刪掉。**

## 還沒解決、已經登記的

| | 問題 |
|---|---|
| 🔴 **最大的漏洞** | 玩家可以**輪流換對象**打低語卡,把腐蝕平均攤在五個人身上。專家實算:**集中打法第 8 張破線,平均分攤能打到 17 張。** 而我原本以為的那股抵銷力量,**方向是反的** |
| 🔴 **兩個必需系統不在計畫內** | 「營火存檔」需要有人喊存檔,「跨線告知」需要有人負責告知——**兩個負責的系統都在 8/25 被降級,都還沒開始** |
| 🟡 劇本量 | 心靈對話約 80 段,對比原本承諾的 3 段 |
| 🟡 美術量 | 腐蝕變體立繪從「氣氛用圖」變成「系統的顯示介面」,**必畫**。好消息是門檻低代表只需 2~3 階 |
