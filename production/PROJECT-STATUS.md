## 一、🔴 你那句「結束回合太容易誤觸」,擋下了一個會讓遊戲卡死的東西

你今天說:**把 Esc 鍵和手把的 B 鍵讓給「取消」,結束回合改放進選單,免得玩家誤觸、白白浪費一回合。**

我照著寫,然後發現一件事:

> **Esc 和手把 B 目前就是玩家唯一能「結束自己回合」的按鍵。**
> 把它們讓給取消、而選單還沒做好的話 —— **玩家永遠無法把回合交給敵人,戰鬥卡死。**

所以這件事**必須兩半一起做**,不能只做前半。我把它寫成三個地方的硬性記錄,還特別寫了一條驗收條件,**那條驗收條件唯一的用途就是防止這件事做到一半就上線。**

### ⚠️ 而這個坑我們已經踩過一次,就在同樣這兩個按鍵上

程式碼裡逐字記著這兩個按鍵當初為什麼要新增:**原本用的那個按鍵沒有手把版本,「否則只用手把的玩家永遠無法把回合交給敵人」。**

**同一句話,同一個功能,第二次。** 第一次是漏掉手把;這次是把按鍵讓出去卻沒準備新家。

## 二、你今天下午裁決七件事,全部已落地

| 你決定的 | 結果 |
|---|---|
| 手牌平常縮小放在畫面下緣,按鍵才展開 | 已落地。**順帶解決了一個沒人在意的技術問題**(手牌一場戰鬥換牌 9~11 次,原本每次都要做登記手續;常駐就只要做一次) |
| 增益還剩幾回合 → 棋子上掛標記,細節靠游標 | 已落地。我用「一點/兩點」而不是數字 —— 因為只有 1 和 2 兩種,而數字在小螢幕上只有十個像素高 |
| 疊多張牌時逐條列出誰加了多少 | 已落地。**這導出一項新的程式義務**:目前只能拿到加總後的數字,拿不到逐條清單,要新增一個查詢 |
| 選作用對象都在棋盤上選 | 已落地。改關係的牌要選兩次(先選一個角色、再選另一個) |
| **Esc/B 讓給取消,結束回合進選單** | 已落地 —— **而它導出第一節那件事** |
| 回合開始三件事同時發生但位置分開 | 已落地。**你加的那半句「留一回合痕跡」才是真正解決問題的部分** —— 見下 |
| 選單入口用專用鍵,不做「同一個鍵看狀況做不同事」 | 已落地。多佔一個按鍵,換來玩家不必記狀態 |

### 為什麼說「留一回合痕跡」才是真正解決問題的那一半

原本的問題是:增益到期和抽新牌撞在同一瞬間,**玩家很容易漏看到期**。

而**再顯眼的閃示都修不了「眼睛剛好在別處」**。你要的那個痕跡(到期的那條在明細裡多留一個回合)把漏看的代價從「資訊永遠消失」降成「晚幾秒才看到」。
