## 二、AI 去背（BiRefNet）

細節在 `deliveries/2026-10-17-ai-matting-trial/README.md`：來源、SHA、授權依據、逐張對照圖。

- 模型：HF `ZhengPeng7/BiRefNet` @ `e2bf8e44`，MIT 授權，SHA256 `9ab37426…a154`。用 ComfyUI 內建節點執行，**不使用雲端節點**。
- 每張約 0.5 s；同一張跑兩次，位元相同。
- 瑕疵（照實列出）：
  - alpha 是半透明，前景內部是 254；
  - 髮緣帶有背景色溢色；
  - 角色輪廓圍住的小塊背景偶爾會留下來。
- 縮到 32×40 之後，溢色和小塊殘留**都看不出來**：邊緣半透明的像素有 89–100% 落在輪廓上，會被描邊蓋掉；最大的殘留塊大約只等於 1 個輸出像素。⚠️ **128×128 以上的尺寸還沒有測**，尺寸越大，這兩個瑕疵越明顯。立繪尺寸確定後，請告訴我方，我方會補測。

## 三、0.4.0 用法（兩個步驟，都在家用端執行）

```
python -I tools/workstation/make_alpha_mask.py IN.png --output-dir DIR
python -m ai_art_postprocess process IN.png --alpha-mask DIR/IN_mask.png --size 32x40 ...
```

- **批次**：用 `--alpha-mask-dir DIR`，工具會依檔名對應 `<stem>_mask.png`。工單的圖都叫 `0.png`，所以請每張工單各跑一次。
- **門檻**：`--alpha-mask-threshold`，預設 128（模型的決策邊界）。實測門檻在 64–192 之間，前景比例只差 0.8%。
- **報告**：`chroma_key.method = "external_mask"`，報告裡會記 mask 的 SHA 和前景比例。
- **可疑偵測在 mask 模式下只保留三條防呆**：去掉的比例 < 0.10、去掉的比例 > 0.95、最大前景塊的佔比 < 0.90。其他指標量到的是構圖，不是去背品質，所以報 N/A。
- **實測對照**：b1 加 4 張動漫圖，`--alpha-mask` 5/5 PASS；`--key-from-edges` 只有 1 張通過。預覽在 `deliveries/2026-10-17-alpha-mask/`。
- 完整說明在 `docs/postprocess.md`。
