## 三、做法(順序固定)

1. **AI 出大圖**:每張先出大圖(尺寸自選,在 README 寫明),俯視、低飽和、無強投影、無文字、無單位。
   視覺語言(逐項,完整版見規格第 4 節):
   - 平地:細碎草紋,橄欖綠。
   - 灌木:圓團葉叢,深綠,滿格。
   - **倒木:一根橫躺的樹幹,左右貫穿或幾乎貫穿圖塊,一端可見年輪斷面,樹幹周圍的底面是平地的綠。不能只是一塊棕色。**
   - 水:水平波紋,藍,滿格,無物件剪影。
   - 懸崖邊/虛空:一側有亮岩緣線,其餘近黑,要有「往下掉」的深度感。
   - 不可進入的兩種**整格都不是綠色**,以便和倒木分開。
2. **後製縮放到 32×32**:縮圖法自選,**在 README 寫明用了什麼、為什麼**。我只審結果。
   縮完必須是乾淨的像素格,不得有重採樣模糊。
3. **量化進 `color-palette.csv`**(64 色上限)。輸出每張實際用到的色盤 hex 清單。
   - 倒木只能用新增的 `nature_fallenlog_*_02` 三階與 `nature_outline_01` 和平地底色;**不得使用舊 `nature_fallenlog_*_01`**(其主色與一名棋子的外套色相同)。
   - 水只用 `nature_water_*_01`;懸崖只用 `nature_void_shadow_01`、`nature_cliff_*_01`。
   - **新增色總數不得超過 10,總色數不得超過 49 / 64。**
4. **修接縫**:四邊相接。同地形 8×8 拼接,人眼看不出接縫。
5. **畫 1px 格線**(量化之後、逐像素直接指定色盤內的顏色,畫完不得再量化):
   - 每格上緣一整列、左緣一整行,各 1px。
   - 色用該地形自己的 shadow 色階:平地與倒木用 `nature_open_shadow_01`、灌木用 `nature_brush_shadow_01`、水用 `nature_water_shadow_01`、懸崖用 `nature_void_shadow_01`。
   - 不得新增格線專用色。
6. **不得有色盤外像素**:交付前自己檢查,在 README 貼出「色盤外像素數 = 0」的原始輸出。

## 四、驗收(由我在看過成品後出;你不要自行判斷通過與否)

本單要特別對準兩點(規格第 5 節的第 3、4 條):

- **第 3 點:倒木必須認得出是倒木。** 有橫躺樹幹的剪影,不只是換色。我會請一位非作者的人看棋盤畫面指認障礙物。
  請你在 README 自檢時回答:拿掉所有色彩只看亮度,倒木是否仍看得出一根橫躺的樹幹?答案寫「是 / 否 / 不確定」,不要美化。
- **第 4 點:棋子疊在每種可走地形上要看得清。** 我會把 5 張正式棋子(藍亭萱、徐培恩、董振豪、秦亦柔、麥子健;`assets/art/characters/pieces/`)疊在平地、灌木、倒木上檢視,共 15 組。
  **董振豪疊在倒木上為重點項**(舊倒木主色與其外套色相同,這是改色的原因)。你不必自己疊,但請在 README 回答:倒木主色與舊 `#6B4A2E` 的明度差你認為夠不夠,寫「夠 / 不夠 / 不確定」。

其餘:尺寸 32×32、拼接無縫、色盤內、格線可數(玩家能數出走了幾格)。完整 7 條見規格第 5 節。
