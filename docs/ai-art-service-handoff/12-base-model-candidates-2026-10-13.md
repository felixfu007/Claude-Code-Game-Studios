## 候選一(建議採用):Animagine XL 3.1

1. **模型識別**:Hugging Face `cagliostrolab/animagine-xl-3.1`,`.safetensors` 格式,
   fp16 約 6.5GB,SDXL 架構(1024² 原生)。
2. **授權/可否商用**:Fair AI Public License 1.0-SD(FAIPL-1.0-SD)。
   允許商業使用;限制針對「修改模型後對外散布」——若合併/微調後讓它對網路可及,須同步
   公開原始碼與相同授權(share-alike)。**沒有查到**它對「只用來產圖、不散布模型本身」
   這件事有額外限制。來源:模型頁授權欄位 https://huggingface.co/cagliostrolab/animagine-xl-3.1
   、授權全文 https://freedevproject.org/faipl-1.0-sd/ 。查證於 2026-10-13。
3. **為何符合畫風需求**(專業判斷):Animagine 系列是在插畫/二次元圖像上微調,不是
   在寫實攝影上微調,色塊邊界天生比 SDXL base 1.0 銳利、陰影層次天生較少,社群
   普遍拿它或其同代血統(見候選二)再衍生出更扁平的版本。**但它本身預設仍非三階硬邊
   cel-shade**,仍有連續漸層陰影——會比現在好,但不會一步到位。
4. **已知風險**:
   - 🔴 Danbooru 標籤式訓練,prompt 需從現行自然語言改寫成逗號分隔標籤(例
     `1girl, solo, standing, flat color, cel shading`)——這不是調整,是**重寫**,
     現有 910/806 字元版本很可能在此底模上效果不佳。
   - 官方慣用採樣組合是 Euler a + Karras;本服務 scheduler 固定 `normal`、無 Karras,
     需額外驗證 `normal` + `euler_ancestral`/`dpmpp_2m` 組合畫質是否可接受。
   - 架構與現行 SDXL base 1.0 相同量級,VRAM 無新增風險。

## 候選二(次選):Illustrious XL v2.0(底模本身,非社群微調版)

1. **模型識別**:Hugging Face `OnomaAIResearch/Illustrious-XL-v2.0`
   (若該版本頁面異動,上游同時提供 `OnomaAIResearch/Illustrious-XL-v1.0`)。
2. **授權/可否商用**:Fair AI Public License 1.0(與候選一的「-SD」變體同家族、
   條文不完全相同)。查到的二手來源(HF 討論串)一致指出:**明確禁止「將微調/合併後的
   模型以封閉原始碼形式商業化」**——任何對外散布的衍生模型(含 LoRA 合併版)須連同
   資料集說明、合併方法一起公開。來源:
   https://huggingface.co/OnomaAIResearch/Illustrious-XL-v1.0/discussions/1 、
   https://huggingface.co/OnomaAIResearch/Illustrious-XL-v2.0/discussions/1 。
   查證於 2026-10-13。🔴 **沒有查到**它是否區分「只用來產圖、不散布模型」與
   「散布微調/合併模型」——這是需要委託方自行確認或諮詢的灰色地帶,本文不代為判斷。
3. **為何符合畫風需求**:Illustrious 這條血統是候選三(Nova Flat XL)等「扁平」社群
   微調版的共同上游,訓練資料整體比 Animagine 更偏插畫/二次元,色塊更乾淨——從這個
   底模出發往扁平方向校正已有社群先例證明可行。
4. **已知風險**:
   - 同候選一,需改寫為標籤式 prompt。
   - 授權條款「禁止封閉原始碼商業化」字樣比候選一更直接,法務風險感覺上更高。
   - 本次查證只看到討論串摘要,未能打開完整 README/LICENSE 全文逐字核對,
     下載前建議自行開啟 repo 頁面重新確認。

## 候選三(僅列風險參考,不建議採用):Nova Flat XL

1. **模型識別**:Civitai model id `1240874`「Nova Flat XL」,版本 `v9.0`,底模為 Illustrious。
2. **授權/可否商用**:🔴 **明確查到可否商用的逐字答案——否定。** Civitai 模型頁
   Permissions 區塊:「未經編輯的生成圖像不得商業使用(轉黑白不算編輯);可免費分享
   圖像但不得營利;歡迎對外宣傳這個模型本身」。來源:
   https://civitai.com/models/1240874/nova-flat-xl ,查證於 2026-10-13。
   除非委託方認定我方既有的量化/去背/後製流程足以構成「編輯」(本文不代為下此法律判斷),
   否則此條款直接擋下商用遊戲素材的用途。
3. **為何仍然列出**:這是本次搜尋中視覺上最貼近「扁平」規格描述的現成檢查點——模型
   名稱與頁面範例圖直接訴求 flat 風格。列出是為了讓管理者看到「風格最接近、代價是授權」
   這個取捨存在,**不是建議採用**。
4. **已知風險**:除授權外,架構、tag prompt、VRAM 需求與候選一二相同量級。

## 建議順序與理由

**①Animagine XL 3.1 → ②Illustrious XL v2.0 → ③Nova Flat XL(不建議)。**

一句話理由:候選一的授權查證最乾淨、沒有「封閉原始碼禁止商業化」這類額外字樣,
且是三者中社群採用最廣、可預期踩坑記錄/討論資源最多的一個——在畫風都只能「更接近、
不能一步到位」的前提下,優先選風險最低的。

## 查不到 / 不確定的項目彙整

- **候選一、二皆查不到**:「只用模型產圖、不對外散布模型本身」是否落在各自授權的
  限制範圍之外——查到的條文都只明確管「修改/散布模型」,沒有查到它們對「輸出圖像
  用途」本身的逐字立場。
- **候選二**:完整 LICENSE 全文連結本次未能逐字核對,只查到討論串摘要。
- **候選三**:「後製流程算不算編輯」無從查證,屬法律判斷而非事實查證。
