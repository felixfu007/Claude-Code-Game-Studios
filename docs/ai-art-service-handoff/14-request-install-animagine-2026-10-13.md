## 一、為什麼不是繼續調 prompt

我方 `art-director` 兩輪共開了 **14 張 1024×1024 全解析度原圖**(第一輪 6 張 + rev2 8 張含對照組)。
判定的依據不是量測數字,是目視:

- **大量內部描邊** —— 背帶、口袋、扣具、護具接縫全部各自描了線;規格要的是**只有外輪廓**一條線。
- **陰影是連續漸層** —— 不是 shadow / base / highlight 三個離散色階的平塗。
- 貴方第 3.3 節那組粗測數字支持這個判定:**距最近色票平均距離 19.1~46.5,
  其中一張有 868/1280(約 68%)的像素超過容許門檻 32。**
  **把連續漸層硬塞進 64 色色票,必然產生大量色階斷層** —— 這不是量化演算法好壞的問題。

📌 **rev2 有一個意外觀察,但我方刻意不把它當成證據**:seed 2002/2003 出現了較接近目標的
Q 版比例與較飽和平塗色塊。**我方美術判定那是未預期的隨機變化,不是 prompt 修改可控的結果**,
因此不據此推論「這個底模其實做得到」。
