## 2. 交件報告「沒做到 / 沒驗證」五點處置
**棋子**
1. **丁的雙手瞄準沒做到 → 第二階段修,不阻擋。** 我看圖:單臂前伸仍讀得出「持槍」,與丙的差異靠姿態與帽簷已夠;但規格要求的大簷帽特徵弱(帽簷 1~2px)。處置:列入第二階段要求(帽簷加寬)。雙手三角瞄準降為「加分、非必要」。
2. **戊的肩歪/S 形小 → 接受,降級。** 戊的身份靠直立+插口袋+刀,在 3x 已與甲分開。要求只改刀的 1x 可見度(見第 3 節),不再要求 S 形。
3. **身寬只有戊達標 → 降為目標值,不退件**(理由見上表)。
4. **棋子量化用到地形色 → 我決定:不做全面限制,改為「大面積限制」。**
   理由:色盤只有 64 色、地形已占 9 個新色,全面禁用會把棋子逼進少數衣色,反而違反灰階/剪影之外的顏色多樣性;且描邊、小塊暗部必須能用深色(`#1E1A17`、`#1B2E3F` 這類是全專案共用的暗階)。真正的問題不是「用到地形色」,而是「大面積主色與棋子可能站的地形同色而被吸收」。規則:
   - 棋子**單一色塊(主衣色/褲色/外套)面積不得使用「該棋子可站地形」的 base 色**:平地 base 色、倒木 base 色(`#3B342E`、`#6B4A2E`)。
   - 暗部、描邊、鞋、頭髮、小於約 15% 輪廓面積的色塊,不限。
   - 水色:水不可進入,但棋子頭部伸出本格上緣 12px,北側格若是水,頭會疊在水上。故**丁(深海軍藍,衣色即 `#1B2E3F` 水影色)須換一階**。可行替代:改用 `metal_*` 或 `cloth_*` 系列的藍灰(色盤內現成,我未逐色核對可用 hex,須外包據色盤挑)。
   - 具體違規(轉述 + 看圖確認):戊褲 `#3B342E` = 倒木底色,**要換**(看圖:戊站倒木格上,褲與樹幹同色糊成一片);丙外套 `#6B4A2E` = 舊倒木底色,**要換**(看圖:丙疊在倒木上身體部分相近)。
   - 這是美術網域裁決,不需管理者決定;若管理者之後反對,可推翻。
5. **管理者盲測沒做 → 見第 6 節,由管理者做。**

## 4. 倒木路線(程式畫剪影 + AI 樹皮)
**接受,有條件。**
- 理由【看圖】:橫躺樹幹、右端年輪、上亮下暗三階,一眼是「一根木頭」;**這一條正是管理者 11-11「色塊看不出代表什麼」的根因,現在是有形狀的物件了,方向對**。程式畫剪影的好處:輪廓由規則決定,能保證「橫躺 + 年輪」,而這是 AI 14 次都達不到的;缺點是樹皮質感只靠 AI 423px,風格可能與棋子不一致——但本專案色盤 64 色限制下,這個差別在 1x 很小。
- 條件:
  1. **尺度**:現在樹幹約 40×15px 且集中在格子上半(看圖),規格要求「高約 20~24px、橫貫圖塊」。**加高至 20~24px、左右各留 ≤2px,位置置中偏下**。否則在 13×8 的棋盤上像「地面上的貼紙」,不像「擋視線的障礙」。
  2. **「擋視線」的暗示**:同格棋子站在其後面時要看得出被遮。建議樹幹明度比平地最亮階低至少一個階(現已做到),並在樹幹上緣加一道 1px 高光(`#9C7A52` 或 `#6E6458`)讓體積感出來。
  3. **2 張變體**:年輪朝左一張、朝右一張,或樹幹略彎一張(規格要 2 張)。
  4. **風格一致**:樹皮 AI 紋路與棋子的像素粗細需一致;不接受樹皮細到變成噪點(現況看起來還可)。
  5. **盲測**:管理者要做「看到倒木格,這是什麼、能不能走、擋不擋視線」三問(第 6 節 B 組)。不通過則改走骨架草圖或手修。
- 疑慮(轉述 + 看圖):倒木格每格都是同一根在同一位置,6×6 拼起來像「整齊排列的木頭」。實戰關卡是單格散布,問題不大;但**若地圖有連續多格倒木,要有 2 張變體交錯**。
