## 1. 五位襯底遮右半身
觀察:襯底是一塊深色長方形,從左側身分標籤(甲/乙/丙/丁/戊)一路橫跨到劍,垂直約在腰到大腿上緣。頭、肩、胸上緣、小腿與腳全部露出。
- 藍亭萱:藏青長外套,腰以下被蓋,辨識靠頭髮與上身深藍,仍可認。**可接受**。
- 徐培恩:灰綠上衣,胸前綠色小點(口袋/徽記)在襯底上緣剛好露出,下半被蓋。**可接受**。
- 董振豪:**最難受的一位**。斜背帶從左肩斜下,在襯底上緣被截斷,看不到它的末端與手;但背帶上半段與棕色上身仍在,仍認得出是同一個人。**勉強可接受,是五位中唯一我會標「難受」的**。
- 秦亦柔:頭戴帽、深藍衣,蓋住的部分本來就暗,襯底幾乎融進衣服。**可接受**。
- 麥子健:紅棕外套,蓋住下襬;紅色主體在上半身仍可見。**可接受**。
總評:襯底遮的是「腰以下共同的暗色區」,各角色的辨識特徵(頭髮、帽、上衣顏色)都在襯底上方。手的缺失是真損失,但全是小地方。**我的美術判斷:四位可接受、董振豪邊緣;是否整體可接受屬 AC5,須管理者人眼。**

結論:鞋合格;**劍在 960 偏弱,建議改亮**。

## 7. 劍改亮的可實作規格(art-director 決定,2026-11-18 追加)

**診斷**:`SWORD_ICON_ROWS` 現行劍身只有 1 像素寬(`OLO` 的中間一格),兩側 `O` = `ICON_COLOR_O` #26303D(metal_outline_01),在深色襯底上幾乎隱形,所以實際看到的是一條 1px 亮線。劍「細」主因是**寬度**,不是色票。色票已經是金屬最亮階(`ICON_COLOR_SWORD_L` = #A9B2BD = metal_highlight_01),沒有更亮的金屬色可換。所以改**陣列形狀**,不改色票。

**新 `SWORD_ICON_ROWS`(仍 7×10,`sword_icon_rect_in_cell()` 的矩形與襯底寬度計算完全不變)**:
```
const SWORD_ICON_ROWS: PackedStringArray = [
	"...L...",
	"..LLL..",
	"..LLL..",
	"..LLL..",
	"..LLL..",
	"LLLLLLL",
	"..GGG..",
	"...G...",
	"...G...",
	"...O...",
]
```
- 劍身 1px → 3px 寬(4 列),護手整列(7px)改用亮色 L,形成一個清楚的「十字」剪影;握柄用 G,底端一格 O 當劍首。
- 符號→色票對照**不改**:`L` = `ICON_COLOR_SWORD_L` #A9B2BD = metal_highlight_01;`G` = `ICON_COLOR_G` #7D766A = cloth_neutral_base_01;`O` = `ICON_COLOR_O` #26303D = metal_outline_01。**全部是 `design/art/color-palette.csv` 既有色,未新增。**
- 亮色像素數:原本約 4(劍身)+5(護手 G 不算亮)≈ 4;新版 1+12+7 = 20 個 L。960 視窗下(2 倍)劍身由 2px 寬變 6px 寬。

**與鞋仍可區分的理由**:
1. 形狀不同:鞋是 9 寬、貼左下的「L 形靴」(左側直立、底部橫向延伸、右上空),劍是 7 寬、置中的垂直十字,輪廓重疊度低。
2. 位置固定:鞋永遠在左、劍永遠在右(`shoe_icon_rect_in_cell` / `sword_icon_rect_in_cell` 不變)。
3. 色相:鞋 #B0A897 偏暖米,劍 #A9B2BD 偏冷藍灰。這一條較弱(亮度接近),**不要單靠它**,所以我明確**不建議**把劍改成 cloth_neutral_highlight_01(那會與鞋同色,只剩形狀可分)。
4. 風險自陳:劍變寬後「鞋加劍」兩者都是一大塊亮色,縮到 960 時可能比現在更像「兩個亮方塊」。我只能從形狀推論,**沒有看過新版實拍**,需實作後重拍 960 的丙(只有劍)與丁(鞋加劍)兩格再判。

**實作注意**:
- 陣列寬高不變,依賴尺寸的測試應不受影響;若有測試逐字比對舊陣列(`OLO` 之類)或逐像素數量,要同步更新,這是需要實作者核對的,我沒讀測試。
- 圖例的「已攻擊」圖示若引用同一個 `sword_texture()`,會自動同步;若另有一份,需一併改(我沒查)。
- 游標停留那張:協調者查證游標未畫進該幀,故不證明白罩效果,記為**未驗證、不阻擋**,我不再查。
- 退路:若重拍後劍與鞋仍難分,下一步是再議劍的形狀(例如更長的劍身),不是換色。

**結論:通過,不需要下一版陣列。** 殘留風險(已知、不阻擋):960 下劍仍只是一個小亮十字,細節(護手與握柄的區分)要到 1920 才看得出;圖例 1920 新版未重驗。
