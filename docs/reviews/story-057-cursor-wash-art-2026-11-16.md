# story-057 游標洗亮首字深底:美術裁決(2026-11-16)

## 1. 問題
story-057 的首字深底有畫、位置也對,但游標所在格的深底看起來變淺。成因是最上層的 `CursorSprite`(`assets/art/placeholder/cursor_outline.png`)中心有 (1,1,1,0.149) 白色半透明填色,整格被洗亮。層序:PieceLabelBackdropLayer < PieceLabelLayer < ActionFlagLayer < CursorSprite。

## 2. 我看過的物證
- `prototypes/story-057-backdrop-capture-2026-11-16/out/1920x1080_2cursor_xu_real.png`(游標在「徐」):徐的首字底是偏灰的深色,白字仍清楚可讀;同圖其他格(藍、蓁、費、董)的底是近黑色,兩者並排可見差異。
- `.../out/1920x1080_1overview_real.png`(游標在「藍」):藍的底變灰,徐的底回到近黑。
- `probe_pixels_output.txt`:徐的底像素游標在上 0.28/0.27、不在 0.16/0.15。數字與肉眼一致。
- 我的判讀:字仍可讀,但「這一格的底被洗成灰」會讓管理者要的「全部加濃底」在游標所在格打折,而游標所在格正是玩家最盯著看的格。

## 3. 選項評估
- A(襯底移到游標之上):襯底貼格左緣,會蓋住游標外框最左一小段,游標外框出現缺口。游標是玩家「我在哪」的主要記號,不該被其他元素切斷,否決。
- B(改游標貼圖):外框保留,只把中心填色在襯底那塊矩形位置挖空(alpha 0)。游標整格仍有淡白填色,只有首字底那塊不洗亮。代價是填色多一個小缺口,0.149 的透明度下肉眼幾乎看不出。
- C(接受現況):白字對比仍足夠(依畫面判讀,未量測比值),但與管理者「全部加濃底」的意圖不一致。

## 4. 裁決與做法
裁決:B(挖空版)。理由:格視覺層級是「外框 > 首字 > 填色」,填色最低,犧牲它的一小塊最便宜;外框完整,游標辨識度不變。
做法(本人只出規格,不改檔):
1. `cursor_outline.png` 的外框像素與整體尺寸一律不動。
2. 中心填色 (1,1,1,0.149) 保留,但在首字襯底矩形(12×14 來源像素,貼格左緣 x0,y 位置照 `board_view.gd` 的襯底節點)所涵蓋的像素,alpha 設為 0。
3. 外框若與該矩形重疊,外框像素保持原樣(只挖填色,不挖外框)。
4. 這是 placeholder 資產;正式游標美術出來時,同一規則寫入驗收:「襯底矩形範圍內不得有半透明填色」。
5. 驗收:重跑同一支探針,游標在上的襯底像素應回到約 0.16/0.12,與不在上時差 ≤ 0.02。
若 B 的工單排不進,退而求其次是 C,不是 A。此決定屬美術範圍內,不需管理者另行取捨。

## 5. 未驗證項
- 未驗證:`cursor_outline.png` 的實際尺寸與外框厚度(開圖只見一張很小的白框,推測 32×32、外框約 1px,未量)。
- 未驗證:襯底矩形在 32×32 格內的確切來源像素座標(未讀 `board_view.gd`);挖空矩形必須由實作者從該檔取值,不得照本文推測。
- 未驗證:`cursor_outline.png` 是否還被其他場景共用;挖空位置固定在格左側,若共用於無單位的格不受影響,但未查證。
- 未驗證:C 的白字對比比值(只依截圖判讀「仍可讀」)。
