## 3. 第 2 題:prompt 長度

**事實(A)**:正式上限 1000 字元;立繪正向 1,081(超 81)、棋子 1,555(超 555)。家用端用只放寬這一項的
臨時實例產圖,正式上限沒動。每次都得開臨時實例,是一個會一直付的操作成本。

**一個值得注意的線索(我的假說,沒驗證)**:沒被服從的項目,棋子 prompt 裡幾乎都在**後半段**
(洋紅背景約第 750 字元、無指手套與斧頭靠肩約第 1,200 字元以後)。可能是模型對長 prompt 後段較不敏感,
也可能只是這幾個詞本來就難。**這個線索我目前無法區分兩者**;
服務對超長 prompt 是截斷還是分段處理,我**未查證**,需問家用端。

| | 推薦:調高上限到 1600 | 替代:縮短 prompt 到 1000 內 |
|---|---|---|
| 白話後果 | 工單可以直接照現有文字送,不用每次開臨時實例。已有的 4 張證據仍然有效 | 要砍掉棋子約 36% 的字、立繪約 8%。砍哪些都是沒測過的改動 |
| 優點 | 立刻消除操作成本;保持證據連續 | 長 prompt 的後段可能被忽略,砍掉重複詞可能反而更聽話;守住原本的上限設計 |
| 缺點 | 上限當初為何訂 1000,我**未查證**(可能有防濫用/穩定性理由),要問家用端;若後段本來就被忽略,調高只是讓沒用的字合法 | 砍字會同時動到「服從度」這個要量的東西,和第 7 節的對照混在一起,**無法歸因** |

我推薦調高,理由是**變因管理**:先把「開頭怎麼寫」測清楚(第 7 節),縮短 prompt 放到再下一輪單獨測
(「把關鍵特徵挪到最前面」對照「原順序」,一次只動一項)。**最終由管理者決定**,
這也牽涉家用端是否同意改正式 config(那是他們的服務)。

## 4. 第 3 題:棋子去背

**事實(A,引自 README 第六節,為家用端量測)**:

- 兩張背景都不是洋紅,是平塗灰藍(`#616F82`、`#7A8193`)。色鍵剛好還能用(取樣 8/8 同色)。
- 色鍵法會把被角色圍住的背景留下:P3 兩腿之間、左腳地面投影、手臂與身體之間,共多留 43,687 px;
  縮到 32×40 後 P3 有 87 格不同(兩腿之間一整塊灰),P4 有 29 格。
- AI 去背法在這兩張都沒被標為可疑;P4 兩種都沒偵測到「角色碰到下緣」(角色被切)。

| | 推薦:AI 去背(`--alpha-mask`) | 替代:邊緣色鍵(`--key-from-edges`) |
|---|---|---|
| 白話後果 | 腿間、腳下的灰色會乾淨去掉,小人剪影清楚 | 兩腿之間可能留一塊灰,32×40 上看起來像穿了一條灰褲襠;腳下陰影也會留 |
| 優點 | **不依賴背景顏色**,模型這次沒畫洋紅也照樣能用;對 10/12「只在外圍剪影描邊」裁決友善(不會在腿間多出一圈內描邊) | 不依賴 AI 模型,結果完全可由規則重現;不會把細東西(如斧柄)當雜訊吃掉 |
| 缺點 | 靠一個 AI 模型,不同版本輸出是否一致,我**未查證**;可能吃掉細部(這次斧柄在 32×40 只剩一條線,兩種方法都一樣) | **要賭背景色**:這次的灰藍離深藍制服夠遠,但其他角色(例如灰米色制服)若背景又不聽話,摳圖就會出錯 |

**連帶事項(需管理者知道)**:`art-tone-direction.md` 第二節表格寫棋子去背是「純色洋紅背景 + 色鍵」。
改走 AI 去背就推翻那一格。立繪已在 10/19 裁決走 AI 去背,棋子跟進等於全素材同一套,是簡化;
但那是既有文件的規則,**需要管理者點頭才能改文字**。

**區域檔與完整管線**:我推薦**這 4 張不做**。理由:這 4 張是探針不是候選(24 號明講);
4_outline 失敗是「沒給區域檔」的預期結果;區域檔要人工標材質區,值得花在管理者看過後選中的圖上。
替代:挑 P4(或 P3)現在就跑一次,先看完整管線的最終成品長相——代價是多花家用端一輪、而且這張圖
膝下被切,本身就不合格,跑出來的成品不能當候選看。區域檔的格式與標註工作量我**未查證**。

## 5. 第 1 題:底模方向

**我的推薦:維持 Cheyenne,繼續下一批探針;先不把 prompt 改回標籤式。**

理由(A):
1. 兩個 Cheyenne 版本在「制服、背帶、馬尾、冷色深藍、嚴肅神情」這些**主體特徵**上服從度相當好;
   沒服從的幾項(見第 6 節)多半是細節與背景色。這代表底模「聽得懂」,問題更像出在 prompt 寫法與長度,而不是底模換掉。
2. 補回標籤式是**假說**:10/19 工單第二節我自己就寫「Cheyenne 對標籤式沒有證據」,標籤式的 `masterpiece, 1girl`
   一類詞帶動漫圖站印記,可能把畫風拉回動漫,而動漫血統正是 10/16 被否決的東西。
   現在只有 1 組 seed,測不出標籤式的淨效果。
3. 風險:**可重複性與身分一致性**。P1 與 P2 的髮型(馬尾/包頭)、臉、臂章都不同,
   看不出是同一人。這不是底模問題,是純 prompt 路線的上限(2026-10-13 rev2 已記錄、當時已是 LoRA 的第 2 筆證據),
   這次是第 3 筆輕證據(**n=2,非結論**)。量產路線不因這 4 張改變。

替代:若管理者看完 B 類圖覺得畫風仍不對,則底模要重選,不是補標籤。

## 7. 下一批探針建議:補回標籤式開頭的對照

**目標**:回答「在 Cheyenne 上,補回標籤式開頭,服從度有沒有變好、畫風有沒有被拉回動漫」。
**變因只動一項:prompt 最前面的那一串開頭字。**

設計:

1. **A 組(對照)**= 這次已跑的 prompt,逐字不變。**B 組(實驗)**= 同一份 prompt,**只在最前面加**
   一串標籤式開頭(取 doc 13 的格式,例如 `masterpiece, best quality, 1girl, solo,`)。其餘全不動,
   包括 negative、CFG、尺寸、sampler。
2. **seed 不能只用 1 個**:換 prompt 後同 seed 的構圖也可能完全不同,單張是雜訊。
   **每組、每模型至少 3 個 seed(兩組共用同一組 seed)**:立繪 2 組×3、棋子 2 組×3,共 12 張。
   每張約 12 秒(README 量測),成本低。
3. **CFG 固定**:立繪用 3、棋子用 3(取兩次探針之間的值,不再把 CFG 當變因;CFG 另開一輪單獨測,
   並且這次要真的只動 CFG、不動 seed——修正我工單的錯)。
4. **先寫好計分表再看圖**(避免看完再找理由):每張逐項勾 ①馬尾 ②全身含腳(棋子)③斧頭靠肩 ④背景色
   ⑤無指手套 ⑥無偽文字/簽名 ⑦內部無黑線。比較兩組的「達成項數平均」。
5. **畫風由管理者盲看**:12 張打散、不標 A/B,管理者只回答「哪些像前 19 張被否決的那種」。
   這是 B 類,我不代判。
6. **預先寫好判定規則**(防事後合理化):B 組若服從度平均 **多 2 項以上**,而管理者盲看中
   「像動漫」的張數**沒有比 A 組多**,才採用標籤式;否則維持現狀。這個門檻是我訂的,管理者可調。
7. **不同時動長度**。長度對照(關鍵特徵挪前 vs 原順序)放再下一輪,免得兩項混在一起歸因不了。
   上限需要放寬到至少 1,700(B 組加字),或沿用臨時實例。

延伸:若 A、B 差異都不明顯,那「服從度差」就不是開頭問題,下一步查服務對長 prompt 的處理(截斷/分段)。
