| 場 | 電腦代打現況(8 組開局,只看「運用好感度」那組) | 我的判斷 |

## 1. 證據與限制(白話)

- 第 3 場兩次敗局(診斷):丁在第 3 回合、丙在第 4 回合,**都是被 E4 補最後一刀**;前一輪都被集火打成重傷(丁剩 10、丙剩 3)後沒有逃掉。任一我方倒下就算敗,所以只死一人就輸。

## 2. 第 3 場「變易」方向(三選一,或都不選)

現況(取自 `vs03_roster.txt`、`vs03_terrain.txt`):我方 5 人在 x=0、y=1~5;灌木/倒木帶貫穿 x=3~6、6 列;敵方一道牆:E1(7,2) E5(7,3) E2(8,1) E4(8,4) E3(9,5)。與我方最近距離 7(第 2 場是 8)。

### 3-A 敵人整體後移 1 格(最單純)
可直接套用(只改敵方 5 行的座標欄):
```
6,E1,...,7,2   ->  8,2
7,E2,...,8,1   ->  9,1
8,E3,...,9,5   -> 10,5
9,E4,...,8,4   ->  9,4
10,E5,...,7,3  ->  8,3
```
- 預期(推論,未量測):敵方晚一回合踏進灌木帶,我方第 1~2 回合有更多時間整隊,「第 1 回合禁止移動」的敗局型態(敵人先推進、我方才進帶)的差距縮小。
- 劇情/教學:敵牆仍貫穿 y=1~5,「堵死退路」的畫面不變;距離變 8,與第 2 場相同,**第 3 場與第 2 場的差異就只剩地形**。丙的近身盲區壓力仍在(敵人穿過帶子後貼身),只是來得晚一點。名冊檔頭註解寫「間距 7(更近)」會過時,需另行更新(那是既有文件,要先問)。
- 優點:改動最小、最容易解釋。缺點:整體都變慢,不針對「補刀者 E4」;可能讓第 3 場比第 2 場還輕鬆(未量測)。

### 3-B 只延後兩個補刀者 E4、E5(針對敗因)
可直接套用:
```
9,E4,...,8,4   -> 10,4
10,E5,...,7,3  ->  8,3
```
結果站位:E1(7,2) E2(8,1) E5(8,3) E3(9,5) E4(10,4)。
- 預期(推論):第 1~2 回合只有 E1、E2 先接觸,E4、E5 晚約一回合才到;兩次敗局的共通點「E4 補刀已受傷的單位」較不容易湊齊。
- 劇情/教學:牆從一直線變成兩層斜列,仍覆蓋 y=1~5,可讀成「前鋒先壓、後面跟上」;沒動地形、沒動我方,丙盲區的教學不變。
- 優點:直接對著診斷出的敗因。缺點:E1 前面形單影隻,第 2 回合我方可能反過來集火 E1,第 3 場整體可能比預期更易(未量測);牆的「整齊感」略減。

### 3-C 把 4 格倒木改成灌木(動地形,不推薦當第一手)
可直接套用(`vs03_terrain.txt` 四列各改一格,`#`→`,`):
```
y=1  ...,#,,......  ->  ...,,,,......
y=2  ...,,#,......  ->  ...,,,,......
y=3  ...#,,,......  ->  ...,,,,......
y=4  ...,,#,......  ->  ...,,,,......
```
- 預期:**方向不確定**。移動更便宜(成本 3→2),但「擋視線」消失,對丙(射程 6)與敵方遠程 E3 都改變射線;雙方都受影響,我無法判斷誰得利。穿越整條帶的最低成本不變(第 0 列、第 5 列本來就沒有倒木,仍是 8)。
- 劇情/教學:地形從「灌木+倒木混雜」變成純灌木帶,畫面辨識度下降,「每條路都要付 2 或 3 成本」的敘述要改。
- 優點:不動敵人。缺點:效果最難預料;**不建議在沒量測前選。**

## 3. 第 4 場「變難」方向(三選一,或都不選)

現況:一道 x=8 的倒木牆(y=0,1,4,5),門在 (8,2)、(8,3);E1 (8,2) 站在門上、E2 (12,0)、E3 (12,5)、E4 (11,3)、E5 (12,2),都在牆外側/後方(x=11~12)。我方 x=0。
**必須保留(劇情)**:E1 守門這個畫面、牆與兩格門、戊(0,5) 的南緣退路。下面三案都沒動這三項。

### 4-A 把 E3 從 (12,5) 拉到 (11,4)(輕;10-29 審查已提過)
可直接套用:
```
8,E3,...,12,5  -> 11,4
```
- 預期(推論,未量測):E3 從「遠角趕路的人」變成牆內第二線火力,門口攻堅感增加;第 1 回合在 x=6~7 帶可能多一個威脅源(E1+E3),但仍遠低於原站位的 4 人齊搆。
- 劇情/教學:E1 守門不變,牆後多一人掩護,「地盤有人看守」更有感;與戊的退路無衝突(E3 離開南線,南緣後撤反而更安全,戊的「留退路」風險略減,**這是副作用,屬 narrative-director 判斷**)。
- 優點:最小改動、已有審查文字支持。缺點:可能增加的難度很有限,量出來可能仍是 8/8。

### 4-B 再加 E5 退到門內 (10,2)(中)
可直接套用(含 4-A):
```
8,E3,...,12,5  -> 11,4
10,E5,...,12,2 -> 10,2
```
- 預期(推論):門後第一線有 E1 加 E5 兩人,E1 一倒 E5 立刻頂上;第 2 回合起壓力明顯上升。風險:E5 攻擊力最強(14,近戰,mp6),離門只 2 格,x=5 前進者有可能被 E1+E5+E4 三人搆到(未量測),10-29 診斷的「x=5 懸崖」可能局部復發 —— 那個懸崖曾讓第 1 回合就死一個人(原站位 0/4)。
- 劇情/教學:更接近原設計「守軍在門內」的樣子,E1 守門仍成立。教學節奏:攻堅更硬,「戊被逼表態」的高風險感回來一些。
- 優點:對「偏易」最有感。缺點:最容易矯枉過正;必須先量。

### 4-C 兩個門各有人守:E4 (9,3)+E5 (10,2)(重,不建議)
可直接套用(含 4-A):
```
8,E3,...,12,5  -> 11,4
9,E4,...,11,3  ->  9,3
10,E5,...,12,2 -> 10,2
```
- 預期:最貼近原設計「守方縮在牆內」,但原站位正是曾造成「第 1 回合 4 敵搆到甲」的形狀,**很可能重回 0 勝**(推論,未量測)。劇情上「一人守門」變成「兩門都有人」。
- 結論:列出來是為了讓你看到界線在哪裡;沒有量測前不要選。

## 4. 「都不改,等真人實打」(我的推薦)

- 做法:第 3、4 場資料維持原樣,等你(或其他真人)實際打過 vs03、vs04 後,依「第一個倒下的人、第幾回合、幾個敵人搆到他」判斷。
- 優點:零改動、零風險;電腦證據弱(兩場都只差 1~2 局),而且電腦的 2 敗被診斷為「站位散、低血不撤」,真人通常不會犯。
- 缺點:時間往後拖;若真人打下來結論相反(例如 vs03 其實很容易),等於白等的只有時間,沒有損失。
- 為什麼我推薦:此前已有三次「電腦量測結論後來被推翻或不可靠」的紀錄(見專案的量測紀律),而 vs04 現行站位本來就是管理者裁決「待實打」的狀態。
