`design/art/art-direction.md` 第 13 行 2026-08-25 裁決「像素風,開發者本人繪製,不外包、
不用素材庫」。2026-09-29 管理者主動告知**他本人不會畫圖**——三個分句共同依賴的前提消失。

**Why**: 一年計畫第 4 階段「能看」(2027-03-29 → 2027-06-28)交付明列「美術風格落地」,
退出條件是「陌生人能自己玩過前 30 分鐘不需口頭解釋」。這是一項有到期日的義務,指派給
做不到的人——本專案登記過的失效形狀之一:不會編譯失敗、不會測試變紅,到期前不會有人發現。

2026-09-29 已依派工單產出 `design/art/art-production-paths-2026-09-29.md`——五條路線的
選項書(完全程式化 / 素材庫 / 外包 / AI 生成 / 改變美術方向),不含裁決。已排除的只有
「素材庫作為主角立繪來源」這一項窄範圍用途(結構性不適用,非程度問題);其餘四條路線
(含推翻「像素風」本身的路線 5,需 `creative-director` 介入)均未拍板。

**How to apply**: 未來任何涉及美術產出方式、`art-direction.md` 硬參數變更、或第 4 階段
排程的對話,先讀 `design/art/art-production-paths-2026-09-29.md` 確認路線是否已拍板——
若仍未拍板,不要假設「像素風開發者本人繪製」這個舊裁決仍然可執行,它的前提已知為假。
若管理者已選定路線,把這條記憶更新為選定結果並記錄裁決日期。
