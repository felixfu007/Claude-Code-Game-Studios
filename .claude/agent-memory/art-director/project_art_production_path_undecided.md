**2026-10-08 更新:路線已拍板,不再是「未定」狀態。** 本記憶原文(2026-09-29 當天)記載
五條路線選項書已寫但未裁決;`design/art/art-direction.md` 裁決紀錄區(2026-08-25 裁決之後
的更新)顯示管理者已選**路線 4:AI 生成** —— 原「開發者本人繪製」分句改為「使用開源擴散
模型(SDXL 或 SD 3.5)在使用者家中桌機(RTX 5070 Ti / 16GB VRAM)本機執行,並訓練角色專屬
模型(LoRA)」。「像素風」與「不外包、不用素材庫」兩分句維持不動。

截至 2026-10-08,這條路線已進入實際執行階段,非僅裁決:
- 後製工具 + 去背 + 色票介面三項需求已正式委託給承接團隊(`docs/ai-art-service-handoff/`,
  AI_IMG 倉庫 `ai_art_service`),見 `06-change-request-001-2026-10-08.md` 與其附錄
  `06a`(美術側需求)、`06b`(LoRA 訓練需求,由 technical-director 撰寫)。
- 去背路線已裁決:純色背景 + 確定性色鍵(chroma key),不採 AI 去背節點(06a 第三節)。
- 色票清單檔初版已建立:`design/art/color-palette.csv`(見 [[project_color_palette_v0_and_06a_format_ambiguity]])。
- 傳輸層(跨機器工單橋接)已驗收通過(06a 第七節第 3 項合稿更正)。

**Why**: 一年計畫第 4 階段「能看」交付明列「美術風格落地」,退出條件是「陌生人能自己玩過
前 30 分鐘不需口頭解釋」,是有到期日的義務。路線拍板前這件事無人能做;拍板後責任轉移到
「AI 產圖管線是否真的能產出可用素材」這個新的不確定性上(5 位角色風格一致性尚未真正驗證,
見下方)。

**How to apply**: 不要再假設「路線未定,需要先幫管理者選」—— 路線已選,現在的工作是
**落地執行**(色票、去背、後製工具規格、LoRA 訓練規格),涉及的是「這個已選路線的具體
規格是否可行/一致」,不是「該選哪條路線」。若未來對話涉及美術產出方式變更,先確認是否
真的出現了推翻 AI 路線的新理由(例:產圖品質不可用、VRAM 實際不夠),不要把舊的「五選一」
選項書當成仍然開放的菜單重新拿出來討論。

**已知未結的下游風險(非路線本身,而是路線執行層面)**:
- 5 位角色風格一致性尚未真正驗證,目前只做了 1 位角色的自我一致性代理測試
  (06a 第七節第 4 項)。
- 16GB VRAM 訓練 LoRA 被判定為「剛好夠、且有前提」而非「有餘裕」。
- `result.json` 資料契約尚無任何檢查結果欄位,待雙方另行修訂。

舊選項書 `design/art/art-production-paths-2026-09-29.md` 與授權查證
`design/art/ai-image-licensing-audit-2026-09-29.md` 仍為有效的歷史依據(裁決依據、
授權查證結論),但**選擇本身已經做出,不要再當成待決選單閱讀**。
