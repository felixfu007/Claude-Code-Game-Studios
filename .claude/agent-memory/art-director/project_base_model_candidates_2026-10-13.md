**背景**:連兩輪(09、11)判定純 prompt 工程 + SDXL base 1.0 無法達到扁平三階
cel-shade 規格(見 [[project_art_production_path_undecided]] 2026-10-13 追加段)。
管理者在我方提出的四個選項中選①「先換一個偏扁平的公開底模」,跳過②定臉優先、
③兩條並行、④暫停——②③④是在知情下被跳過的,不要回頭推翻。

**產出**:`docs/ai-art-service-handoff/12-base-model-candidates-2026-10-13.md`,
三個候選、授權逐一查證(查證日期 2026-10-13,獨立於 `04-security-and-licensing.md`
2026-10-05 的既有查證,因為 04 第五節第 2 點明文要求「不同模型授權不能互相套用」)。

- **候選一(建議)**:Animagine XL 3.1,HF `cagliostrolab/animagine-xl-3.1`,
  FAIPL-1.0-SD,查無「輸出圖像受額外限制」的字樣,查無「封閉原始碼禁止商業化」字樣。
- **候選二(次選)**:Illustrious XL v2.0 底模本身,HF `OnomaAIResearch/Illustrious-XL-v2.0`,
  FAIPL-1.0(非 -SD 變體),查到的二手來源**明確**寫「禁止封閉原始碼商業化微調模型」——
  比候選一的授權字樣更嚴格,風格上可能更貼近目標(是候選三的上游血統)。
  **若下一步真的要選這個,先重讀一次完整 LICENSE 全文**,本次只查到討論串摘要。
- **候選三(列入但不建議)**:Nova Flat XL,Civitai model id `1240874` v9.0。
  視覺上三者中最貼近「扁平」,但 Civitai 模型頁**明文禁止未編輯輸出商用**——
  直接的商用阻擋,不是灰色地帶。

**兩個候選共通的風險,尚未解決**:
1. **Prompt 必須從自然語言改寫成 Danbooru 標籤式**(兩者都是 tag 訓練)——現行
   910/806 字元版本預期在新底模上效果不佳,這是重寫而非調整。
2. **候選一、二皆查不到「只產圖不散布模型是否落在限制外」的逐字答案**——查到的條文
   都只管「修改/散布模型」本身,沒有觸及「輸出圖像用途」。這點交回管理者/委託方自行
   確認或諮詢,本文未代為下法律結論。

**How to apply**:下次有人要繼續這條線(安裝底模、測試輸出、或重新比較候選)時,
先讀 `12-base-model-candidates-2026-10-13.md` 全文,不要重新搜尋——除非距今已久、
需要重新查證授權是否變動(`04` 文件本身提醒授權條款會隨時間修改)。若管理者最終選了
候選一或二,**下一步必然要重寫 prompt 格式**,這不是附帶工作,是換底模自帶的代價,
在規劃下一張派工單時要把這項算進範圍,不要漏算。
