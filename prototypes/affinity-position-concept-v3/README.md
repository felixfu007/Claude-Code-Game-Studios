# 原型:好感度—位置連鎖 v3(遠程武器)

## 假說

如果我方攻擊距離依武器種類拉長(2-3 格,弓箭/彈弓/投擲物/槍),不再需要貼身肉搏才能攻擊敵人,玩家會有足夠的空間同時處理好感度佔位,不再讓「戰鬥站位」跟「好感度站位」互相排擠。

**單一變數對照**:好感度規則、數值(+3/-1/+2/-1)、動態劇情事件、移動力,都跟 v2 完全一樣,只改攻擊距離這一個變數(敵方仍保持近戰,射程 1)。

這次調整來自使用者對 v2 的觀察:「腳色的攻擊距離太短,導致短兵相接的時候,擠成一團,無法顧及好感度佔位。」

延續自:
- `prototypes/affinity-position-concept/PIVOT-NOTE.md`(v1 → v2)
- `prototypes/affinity-position-concept-v2/PIVOT-NOTE.md`(v2 → v3)

## 如何執行

直接用瀏覽器開啟 `prototype.html`(雙擊或拖進瀏覽器視窗,不需要伺服器)。

武器配置:A 弓箭(射程3)、B 彈弓(射程2)、C 投擲物(射程2)、D 槍(射程2)、E 弓箭(射程3);敵方 X/Y/Z 皆為近戰(射程1)。

操作方式與 v2 相同,差異在於:選中角色後,棋盤上會多顯示一層淡橘色的「攻擊範圍」提示,且可以點選範圍內(不需相鄰)的敵人發動攻擊。

## 發現

假說 CONFIRMED。拉長攻擊距離後,測試者確認有足夠空間同時處理好感度佔位與戰鬥站位,且首次體驗到遊戲核心幻想(「運籌帷幄」)。經過三輪原型(v1 Paper → v2 HTML → v3 HTML),核心機制「好感度—位置連鎖」得到足夠證據支持進入正式設計階段。仍待正式設計階段驗證的問題:機制的決定性(沒有它就打不贏的關鍵戰鬥情境)、動態好感度事件的觸發頻率調校。完整報告見 [REPORT.md](REPORT.md)。
