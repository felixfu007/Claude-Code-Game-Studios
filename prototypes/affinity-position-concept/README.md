# 原型:好感度—位置連鎖(Paper)

## 假說

如果玩家必須同時考慮標準戰術計算(威脅範圍、地形、傷害)以及角色間的正負好感度佈局,他們會覺得這是有趣的額外深度,而不是混亂的干擾。

**最風險的假設**:玩家能否記住多重(4-6 對)好感度關係,並在戰術決策時同時運用,而不覺得負荷過重或懲罰隨機。

## 如何執行

這是紙上原型,不需要程式:
1. 讀 `rules.md`,準備 6x6 棋盤、6 個我方令牌、3 個敵方令牌、一顆 d6
2. 依 `rules.md` 的規則與「好感度關係圖」設置初始佈局
3. 對照 `play-log.md` 的範例節奏,自己或找人跑一場模擬對局
4. 依 `rules.md` 底部的主持人提示,記錄每步移動前的預測是否正確

## 發現

假說部分成立(PARTIALLY CONFIRMED)。核心鉤子(好感度轉譯為戰術優勢)有效且讓玩家有感,但目前設計的懲罰感強於獎勵感,且好感度關係固定寫死會導致陣型固化、削弱策略新鮮感。完整報告見 [REPORT.md](REPORT.md),轉向方向見 [PIVOT-NOTE.md](PIVOT-NOTE.md)。後續已進到 `prototypes/affinity-position-concept-v2/`(HTML 路徑)。
