# PIVOT Note:好感度—位置連鎖 v4 → v5(Track A 戰鬥端)

> 承接 `REPORT.md` 的 PIVOT 判決。此筆記是 v5 原型的起點,`/prototype` 執行時應優先讀取此檔案,
> 以修訂後的假說作為起點,而非從零開始定義假說。

## 原始假說(v4)

如果讓真正新手在教學後遊玩 2-3 場戰鬥,使用固定節奏發牌、預判標記 UI、非空間取捨機制、遠程武器
空間餘裕,他們會覺得運用好感度佈局是自然且高效的取勝方式——量測門檻:預判準確率 ≥80%、探針關卡
回合數減少 ≥20%(或零重傷)、觸發卡牌組陣型重複率明顯低於未觸發組。

## 判決:PIVOT

**原因**:測試場景本身的缺陷(敵我雙方站位每次重開都固定不變)讓最關鍵的假說項目——機制決定性、
卡牌必要性——完全沒有被真正驗證到。玩家單靠一組固定陣型、完全不打卡牌就能穩定通關,不是因為機制
沒用,而是因為測試場景從未逼玩家面對「這次站位不一樣,舊解法行不通」的情境。

## 什麼有效,下一版要保留

全部保留,測試者反應皆正面:

- 遠程武器空間餘裕的方向(拉長攻擊距離解決擁擠問題,v3 起已驗證)
- 固定節奏發牌(節奏固定、牌面隨機、玩家決定是否打出與作用對象)
- 非空間取捨機制(同一單位同回合僅最近一對正好感生效,負好感永遠全部生效)
- 預判標記 UI 的呈現方式(問題不在呈現方式,而在於它目前只是量測工具、沒有接上任何獎懲,
  導致玩家感覺不到它的作用——這是溝通/設計缺口,不是要拿掉它)

## 最重要的改變

按優先順序,四項改動要一起做,才能真正壓力測試決定性與卡牌必要性:

1. **敵我雙方初始站位改為隨機**——僅供 v5 測試用,目的是模擬不同關卡場景,逼玩家每次面對不同局面、
   不能死背同一組陣型。**正式遊戲的關卡仍維持手工設計,不採用隨機站位**(對照
   `design/gdd/game-concept.md` MVP 必要內容的「至少 5 場手工關卡」要求,以及反支柱明確排除隨機
   決定戰鬥結果——隨機化僅是本輪測試方法論的手段,不是要修改正式設計方向)
2. **卡牌牌面池新增兩種**:強化正好感加乘效果、強化負好感加乘效果——讓卡牌的戰術份量更明確,
   給玩家更強的動機去使用它,而不只是翻轉極性這種效果模糊的變動
3. **敵方新增遠程攻擊單位**(不再全數近戰)——增加戰場戰術複雜度,避免玩家找到「敵人都是近戰、
   我全遠程」這種一招通用的退化解法
4. **我方與敵方攻擊距離各再 +1 格**——進一步拉大戰場空間餘裕,讓玩家在面對隨機站位時,仍有足夠
   空間調整陣型因應,不會因為站位隨機化而意外重現 v2 的「擠成一團」問題

## 額外承接(超出 v5 範圍,但不能遺漏)

測試過程中發現一個 v1-v4 與五輪 design-review 都沒有觸及的問題:若好感度數值真的跨戰鬥累積、且有
初始值繼承,正好感配對會越滾越正、負好感配對越滾越負,長期下來可能讓部分配對永遠無法和解,玩家因此
達不到「完美結局」。測試者提出的解法是拆分「局內好感度」(每戰歸零、供戰鬥站位加成使用)與「局外
好感度」(跨戰鬥累積、依局內結果每戰小幅增減、真正驅動故事結局)。

**這個問題 v5 原型測不到**(v5 仍是單場戰鬥規模,不模擬多場戰鬥的長期累積),也**不完全相容於
`game-concept.md` 現有的「單一數值池、雙重讀取」敘事軌跡架構**(第三、四輪 design-review 裁決)。
建議在 v5 完成後,連同 v5 與 Track B(敘事端)的結果一起,回到 `/design-review` 重新提交這個發現,
交由 creative-director 裁決是否需要調整現有的敘事軌跡架構,而非直接假設測試者的方案可行就自行採用。

## 修訂後假說(v5)

如果讓真正新手在教學後遊玩 2-3 場**站位隨機**的戰鬥,敵方包含遠程單位、雙方攻擊距離皆 +1 格、
卡牌池擴充為 5 種(含正好感/負好感加乘型),他們會發現固定陣型無法穩定通關(機制展現出真正的決定性),
因而主動運用好感度佈局與卡牌因應每次不同的站位——我們會知道這是真的,如果:(1) 同一位測試者在
不同站位的戰鬥之間,實際採用的陣型明顯不同(而非重複套用同一組解法);(2) 卡牌因為有更明確的加乘
效果,測試者主動選擇使用它的比例提高;(3) 預判準確率、探針關卡對照、陣型重複率等既有量測門檻,
這次能收集到不被固定陣型污染的乾淨數據。
