# 原型:好感度—位置連鎖 v4(新手驗證批次 · Track A 戰鬥端)

## 假說

如果讓 3-5 位真正新手(未接觸過本概念、非團隊成員)在教學後遊玩 2-3 場戰鬥,使用固定節奏發牌(每 2 回合)、
預判標記 UI、非空間取捨機制(同時只有一對正好感生效)、遠程武器空間餘裕,他們會覺得運用好感度佈局是自然
且高效的取勝方式——我們會知道這是真的,如果:

1. **預判準確率**:第 2-3 場戰鬥達到 ≥80%(暫定值,待本輪校準)
2. **佈局運用行為**:在決定性探針關卡上,運用佈局的跑法比忽視佈局的跑法回合數減少 ≥20% 或零重傷
3. **陣型重複率**:觸發卡牌事件的戰鬥,陣型重複率明顯低於未觸發的戰鬥,且此差異在遮蔽地形關卡依然成立

這是 `design/gdd/game-concept.md` 第三、四、五輪 design-review 裁決明確要求的硬性門檻(非可選),必須在
進入 `/design-system` 之前完成。詳見該文件「下一步」清單與「MVP 定義」章節的驗收協議。

## 與 v3 的差異

v1(Paper)→ v2(HTML)→ v3(HTML,遠程武器)驗證了核心機制方向正確,但只有 **1 位內部測試者**(且歷經多輪
測試已非新手)。v4 不是單一變數對照,而是同時把 design-review 三輪裁決要求的多項量測工具與機制調整綁在
一起(design-review 稱之為「v4 原型批次」),交給真正新手驗證:

| 項目 | v3 | v4 |
| --- | --- | --- |
| 動態好感度事件 | 每 2 回合隨機翻轉一對關係 | 每 2 回合固定發一張卡牌,牌面隨機,**玩家決定是否打出、對誰打出** |
| 取捨結構 | 無 | 新增:同一單位同時有多對正好感時,每回合只有距離最近的一對生效(負好感永遠全部生效,不受此限)——非空間取捨機制,取代第二輪原先被否決的「站位互斥」方案 |
| 預判 | 無 | 新增:移動前可標記預期效果(加成/懲罰/無效果),移動後自動比對並累計準確率 |
| 地形 | 僅標準地形 | 新增:可切換「遮蔽地形」關卡,測試視線阻擋是否架空遠程武器的空間餘裕 |
| 測試者 | 1 位內部測試者(重複多輪) | 目標 3-5 位真正新手 |
| 陣型量測 | 無 | 新增:每回合記錄存活單位鄰接圖,自動計算「陣型重複率」,依是否觸發卡牌分組比較 |

## 如何執行

直接用瀏覽器開啟 `prototype.html`(雙擊或拖進瀏覽器視窗,不需要伺服器)。

**建議測試流程(每位新手測試者)**:

1. **教學**:讓測試者讀一遍畫面上方的操作說明,不要額外口頭引導(除非他們完全卡住超過 1 分鐘)。
2. **標準地形,第 1-2 場戰鬥**:記錄預判準確率、是否自發運用好感度佈局、有沒有出現「擠成一團」或「無視好感度」的抱怨。
3. **標準地形,決定性探針關卡對照**:同一位測試者(或設計者本人)先跑一次「刻意忽視好感度佈局」,記錄回合數與我方陣亡數(見畫面上「戰鬥結果摘要」);再跑一次「運用佈局」,比較兩次結果是否符合 ≥20% 回合數減少或零重傷的門檻。
4. **切換到遮蔽地形,再跑 1-2 場**:確認遠程武器的空間餘裕在有遮蔽物時是否依然成立,記錄是否出現新的「擠成一團」抱怨。
5. **收尾**:用 `/prototype` 標準的 Phase 6 debrief 五問(假說是否成立、最佳時刻、最糟時刻、意外之處、PROCEED/PIVOT/KILL)逐一詢問。

畫面右側的「本次 Session 統計」面板會自動累積跨戰鬥的預判準確率與陣型重複率(依觸發/未觸發分組)。
**重新整理瀏覽器頁面會清空這個累積數據**,同一位測試者的多場戰鬥請勿中途重新整理頁面,只用畫面上的
「重新開始本場戰鬥」或地形切換按鈕開始下一場。

## 已知簡化(相對於正式規格)

- 移動路徑不會被遮蔽地形的障礙格「擋路」(單位仍可繞行到障礙格外的任何可達格),只有「站在障礙格上」被禁止、以及「隔著障礙格的遠程攻擊視線」被阻擋。正式系統的路徑阻擋規則留待 `/design-system` 定義。
- 疊加規則的正式版本(相加/取極值/優先順序 + 同時生效對數上限)尚未在 `/design-system` 定案;本原型的「同時只有最近一對正好感生效」是為了驗證「非空間取捨機制是否讓玩家感覺到取捨」而選定的一種具體實作,不代表最終規則。
- 卡牌牌面池僅 3 種(翻轉/新增正好感/新增負好感),正式系統的完整牌面池留待 `/design-system`。
- 發牌節奏 N=2 為滿足「典型戰鬥至少發牌 3 次」邊界約束所選的暫定值,非最終校準值。
- 陣型重複率統計僅在單次瀏覽器 session 內累積,無法產生具統計顯著性的樣本量——本輪按 design-review 裁決,僅取方向性訊號。
