# 1. 攻方吃虧、守方吃利:我方要穿過 x=2~6 的灌木/倒木野地(成本 2/3、倒木擋視線),

#    E2/E4 在其後(x=9,y=2/3),遠程 E3(x=10,y=2)從牆後覆蓋兩個缺口——敵方火力

#    我方若集中打一個就被另一個側擊,若分兵就要同時處理兩處——高壓下才看得出好感度
#    站位(甲乙相鄰、丙丁拉開)與發牌節奏是否還站得住。
# 4. 敵方起始間距最近 8(同 vs02),但野地讓我方實際接近時間最長。
