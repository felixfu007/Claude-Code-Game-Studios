# ── 這一關要體現什麼 ──────────────────────────────────────────────
# design/quick-specs/mvp-five-levels-skeleton.md 第一部分、第3場《正面交鋒》節拍
# 逐字:「從『可迴避的遭遇』變成『無法迴避的正面衝突』——丙的近身盲區在真實戰鬥
# 壓力下首次被玩家真正感受到。」(場景:「追兵堵死退路,五人首次無法繞開、必須
# 正面硬打一仗」)
# 做法:
# 1. 地形:vs02 南北兩側邊緣是全通空地、可繞開中段;本場把灌木/倒木帶拉成貫穿
#    全部 6 列(x=3~6),沒有任何一列是乾淨空地——「繞開」在本場不是變難,是
#    不存在(每條路都要付灌木 2 / 倒木 3 的移動成本)。
# 2. 站位:敵方五人沿東側 x=7~9 排成一道牆(前排 E1/E5 在 x=7、中排 E2/E4 在
#    x=8、遠程 E3 在 x=9),覆蓋 y=1~5,代表「堵死退路」;我方背後是棋盤西緣,
#    無處可退。
# 3. 丙的近身盲區:丙(射程 2~4)站在隊伍正中,前方是要穿越的灌木帶;敵方前排
#    E1/E5 一旦衝過帶子貼身,丙就落入 min_range=2 的盲區——這是用站位製造
#    壓力,不是改任何數值。
#
# 地形設計說明寫在這裡、不在 vs03_terrain.txt:該檔格式不支援任何註解行(Board.from_ascii()
# 逐行比對列數與欄寬,同 vs02 檔頭已述)。terrain 內容:逗號=灌木成本2、井號=倒木成本3
# 且擋視線、皆可通行;x=3~6 為貫穿全高的帶狀地形,x=0~2 為我方出發區,x=7~12 為敵方側空地。
#
# ── 數值:一律沿用 vs02 ──────────────────────────────────────────────
# 我方五人 hp/atk/def/mp/射程六欄、敵方 E1~E5 六欄逐一沿用 vs02_roster.txt(權威來源
# design/quick-specs/unit-stats-provisional.md,非本檔職權)。不引入新的未校準數字,
# 敵人數量維持 5(roster_from_text 逐行解析、未限定人數,但不動數量是最小風險)。
# 本場只改地形與敵方起始座標。我方座標與 vs02 相同(丙在第 3 位、全員 x=0)。
#
# ── 座標設計理由 ────────────────────────────────────────────────────
# 敵方最近者 E1/E5 與我方前緣間距 7(vs02 為 8)——更近,但帶狀地形的移動成本讓 E1
# (mp6)一個回合內無法穿越 4 格帶(最低成本 ≥ 8),所以第 1 回合不致被直接貼身
# (⚠️ 未驗證,這是手算推論,沒跑引擎)。遠程 E3 在 x=9,射程 4 在第 1 回合打不到 x=0。
#
# ── 刻意沒做的事 ────────────────────────────────────────────────────
# - 沒有改敵人數量、沒有改任何六欄數值。
# - 沒有讓地形不可通行(引擎無此概念,全部可通行);「堵死」靠成本與站位,不是牆。
