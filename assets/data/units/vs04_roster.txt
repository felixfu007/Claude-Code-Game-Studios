# 集團據點邊緣,戊第一次被逼著表態卻仍只顧自己留退路」)
# 做法:
# 1. 地點帶背景:地形是一座「有圍牆的據點」——x=8 一道倒木牆(# 擋視線),只在 y=2、y=3

#    地方(敘事),玩家則被迫在「進門」與「在外面耗」之間做選擇。
# 2. 戊的退路:我方出發區(x=0~7)大片空地,南北邊緣(y=0、y=5)牆外也是通路,
#    戊(站 y=5,最南)永遠有一條遠離門口的後撤路線——「想表態、卻留退路」由站位與地形
#    給出可能性,是否真走那條路是玩家的選擇(⚠️ 戊的敘事反應不是關卡資料能表達的,
#    屬 narrative-director 職權,本檔不決定)。
# 3. 與第3場的差異:第3場是不得不穿過的帶狀地形;本場外圍較空曠,壓力來自「攻堅」。
