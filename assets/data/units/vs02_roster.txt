# 擋視線、皆可通行),代表追蹤者留下的痕跡——玩家必須跨越或繞過它才能
# 接近/遠離敵方。南北兩側邊緣(y=0、y=5)刻意維持全通空地。

# ── 數值:我方原封不動,敵方沿用 vs01 基準 ────────────────────────────
# 我方五人 hp/atk/def/mp/射程六欄逐一沿用 vs01_roster.txt(權威來源
# design/quick-specs/unit-stats-provisional.md,非本檔職權)。敵方 E1~E5
# 同樣六欄沿用 vs01 對應敵人數值,刻意不重新設計——數值仍是暫定值,派工單
# 明寫不必為精細平衡花時間,重用基準不引入新的未校準數字。本場唯一的新
# 設計是起始座標。
#
# ── 座標設計理由 ────────────────────────────────────────────────────
# 1. 丙(id 3)由 vs01 的「比隊友多站一格」(start_x=1 對其餘人的 0)改為
#    與隊友同一縱隊(start_x 全為 0),排在隊伍正中間(第 3 位)。起因:
#    production/epics/tactical-combat/story-019(2026-10-16)真實量測顯示,
#    vs01 原座標下雙方皆由 GreedyTacticalAI 驅動時第 1 回合即 DEFEAT、
#    敵方五人毫髮無傷——丙(22 HP、射程最遠 2~4)被貪婪 AI 優先推進敵方
#    威脅圈後遭兩面集火致死。這不保證 AI 不會在本場再把他推出去(那是 AI
#    行為,地圖座標管不到),但至少不讓座標本身先替他多跨那一步。
# 2. 敵方起始距離刻意比 vs01 更遠:最近的 E1 與我方前緣間距 8(vs01 最近
#    的敵人 E4 間距僅 6),其餘四名敵人間距 11~12(vs01 為 10~11)。依據
#    同一份量測:vs01 那個間距下,雙方第 1 回合的移動+攻擊範圍合計就足以
#    咬上最脆單位,拉大距離是方向正確的緩解。
#
# ── 刻意沒做的事 ────────────────────────────────────────────────────
# - 沒有改變棋盤尺寸:BOARD_WIDTH=13/BOARD_HEIGHT=6 是 board.gd 寫死的
#   引擎常數(已讀原始碼確認),vs02 與 vs01 必須同為 13×6,不是本檔的
#   設計選擇。
# - 沒有讓地形形成強制接戰的硬性瓶頸——南北兩側仍是全通空地,雙方理論上
#   都能繞開中段斜帶。這條斜帶是敘事與局部視線/成本干擾,不是接戰計時器,
#   「無法迴避的正面衝突」留給第 3 場《正面交鋒》。
# - 沒有改動任何主角或敵人的六項數值欄位,只換了座標。
