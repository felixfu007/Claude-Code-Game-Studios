## 1. 詞彙

| 用詞 | 意思 | 會不會隨走位改變 | 資料欄位 |
|---|---|---|---|
| **關係**(好感 / 敵意;無關係 = 冷淡) | 這兩人合不合 | 不會 | `AffinityLineStatus.polarity` |
| **效果**(加成 / 懲罰 / 無) | 依現在距離,這條線此刻是正、負或零 | 會 | `AffinityLineStatus.state` |

- 「極性」一詞**只**指關係。凡舊文件把「極性」用在效果上,以本表為準。
- 「中立」只能形容**效果**,不得形容關係。
- 資料已齊:`AffinityLineStatus` 同時有 `polarity` 與 `state`,**不需新增資料出口**(協調者 2026-11-06 核 `src/gameplay/affinity/affinity_line_status.gd`)。

## 2. 規則

- **R1 線形 = 關係。** 好感 = 實線;敵意 = 鋸齒線;冷淡 = 沒有線。形狀只看 `polarity`,不隨距離改變。
- **R2 線色 = 效果。** 正(加成)= 暖金、負(懲罰)= 紅。正 = 新增淡金 `ui_state_affinity_gain_01`(建議試畫值約 #F2DE8A,**待試畫、列名待美術確認**;管理者 2026-11-17 裁決「新增淡金色」),負 = `ui_state_negative_01` #FF5252 維持。棋盤與關係圖**統一用此處色值**;棋盤綠 `AFFINITY_LINE_COLOR_POSITIVE` 與關係圖現行另一組色值一併廢止。
- **R3 棋盤:效果為 0(距離 2)不畫線**,也不畫任何灰線/淡線。`MUTED` 筆畫不再出現在棋盤上。**棋盤只畫目前選取者相關的線**(11-12 裁決);**冷淡不畫線**。
  - 距離 2 時棋盤看不出兩人有關係 —— 管理者知情接受,補償是游標預覽:預覽時線依**假想站位**重算(現行 `battle_screen.gd` 已如此,`line_positions = hypo`),所以游標停在目標格就能看到走過去會出現哪種線。
- **R4 關係圖:冷淡不畫線;好感/敵意才畫線**(形狀 = 關係;有線 = 有關係,完全沒線 = 冷淡;節點仍在)。效果非 0 時上色並帶 R5 符號;效果為 0 時線用 `metal_base_01` #6B7280、**不透明(不用 alpha)**、**不放任何符號**,形狀保留。現行「NEUTRAL 畫虛線 + 符號 `0`」**刪除**(虛線會和鋸齒線混淆);「十條一律畫出」「節點色 `COLOR_NODE` 約 0.6 不透明」作廢。
- **R5 效果的非色彩第二通道(必要)**:線中點放 **7×7 不透明深色牌**,牌內以 **5×5 圖元**畫 `+` 或 `−`(圖元,不用字型)。棋盤與關係圖同一套。效果為 0 不放牌。
  - 理由:形狀已讓給關係,若不加這一通道,「加成/懲罰」只剩金紅,違反 `design/gdd/game-concept.md`「正/負好感連線不得僅靠色彩區分」。落選方案(線寬、端點標記、明度差)與理由見美術回答第 3 題。
- **R6 不顯示強度。** 線寬恆定,無強度數字(2026-10-28 裁決第 21 項;`amp` 恆為 1)。若未來卡牌系統讓強度變化,是新的裁決。
- **R7 關係圖詳情區**:每列 = 對象名 + 關係文字(好感/冷淡/敵意;冷淡也列出文字,管理者 2026-11-17 裁決)+ 目前效果。這是文字,只在關係圖內(玩家主動開),**棋盤上不出現「好感/冷淡/敵意」字樣**(保護教學探針)。
- **R8 色盲模式**:形狀(R1)與符號牌(R5)不隨模式改變;模式只換 R2 色值。綠已不存在,**替代色規則重寫**:金 vs 紅以亮度分(美術手算約 1.95:1,未驗證),初值**不換色相**,以「金/紅(及淡金)× 三種色盲模擬樣張」驗證;驗不過再從色票挑替代。美術回答第 6 題的綠紅替代色作廢。若專案已有色盲模式定義則以既有者為準。

## 4. 驗收條件

- **AC-P1 形狀只由關係決定**:同一對角色在距離 1、≥3 時形狀相同;以 `affinity_line_dicts` 輸出斷言形狀欄只取決於 `polarity`。
- **AC-P2 顏色只由效果決定**:好感 + 太遠(負)= 實線 + 紅;敵意 + 相鄰(負)= 鋸齒 + 紅;兩者形狀不同、顏色相同。加成(正)= 淡金,與懲罰紅同樣只由效果決定。
- **AC-P3 棋盤 0 效果不畫**:效果為 0 的對不產生任何線節點,且棋盤上不存在 `MUTED` 筆畫。
- **AC-P4 關係圖:冷淡不畫、有關係才畫**:冷淡配對無線(詳情區列 `冷淡`);好感/敵意配對有線;效果 0 者用 `metal_base_01` #6B7280 不透明、無符號牌、形狀保留;不存在虛線路徑。
- **AC-P5 預覽一致**:游標停在假想目標格時,棋盤連線依假想站位重算,距離變為 2 的線消失、離開距離 2 的線出現,形狀正確。
- **AC-P6 非色彩**:灰階截圖下,僅憑形狀 + 符號牌即可分辨「好感/敵意 × 加成/懲罰」四種組合。加成淡金/懲罰紅在灰階下的亮度差(美術手算約 1.95:1,未驗證)以樣張人眼確認。
- **AC-P7 同一來源**:「`AffinityLineStatus` → (形狀, 色調, 符號)」轉換只有一處,棋盤與關係圖共用(以 `^static func` 錨定 grep 驗證)。
- **AC-P8 棋盤無字**:棋盤連線不出現「好感」「冷淡」「敵意」等文字。
- **AC-P9 無強度**:棋盤與關係圖皆無強度數字,線寬恆定。
- 既有測試斷言 `line_tone_for`、`LineTone.MUTED`、關係圖 NEUTRAL 虛線者會紅 —— 須**有意識地改斷言**,不得刪測試。
