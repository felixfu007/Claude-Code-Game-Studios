*標示:【取樣】= 直接取自現有三段台詞,有物證;【推測】= 由小傳推出,**現有劇本沒有這個人這類台詞**;麥子健全部為【推測】。*

## 通則

1. **個性不隨關係狀態改變,變的是願意說多少。** 好 = 多說一句;冷淡 = 只說該說的;壞 = 話變少或變尖,但仍是同一個人的說法。
2. 每句 ≤ 40 字(硬上限 120 字,`narrative.md`)。不用難以翻譯的成語與典故;口頭禪用名稱化的短句,不用諧音梗。
3. 台詞用全形標點;沉默寫「……」,不寫舞台指示(資料檔不收〔〕)。
4. 稱呼會隨狀態變:好 = 更近一點(省姓或改稱呼),壞 = 回到全名或職稱。下表只列預設稱呼。
5. 名冊 id:1 藍亭萱、2 徐培恩、3 董振豪、4 秦亦柔、5 麥子健。

## 一、藍亭萱

| 項目 | 內容 |
|---|---|
| 一句話 | 直率衝動,先做後解釋。 |
| 口頭禪 | 「知道啦。」「哈。」「……那我繼續衝了喔。」【取樣 SC-01】 |
| 句長 | 短,多數 5~15 字,常是一個問句加一個結論。 |
| 用詞 | 口語、動作字(衝、擋、破、問);語助詞「啦、喔、吧」。 |
| 慣用句型 | 直接問「你怎麼…」「你是不是…」;不喜歡的事直接說「我不喜歡…」【取樣 SC-02】。 |
| 禁用 | 官腔與書面語(「請問」「據我所知」);不替別人做心理分析;不說客套轉折。 |
| 怎麼稱呼別人 | 徐培恩:「你」,好態可說「夥伴」【取樣】。董振豪:「董振豪」「你」【取樣 SC-02】。秦亦柔:「秦亦柔」「妳」【推測】。麥子健:「麥子健」「你」【推測】。 |

## 二、徐培恩

| 項目 | 內容 |
|---|---|
| 一句話 | 克制平穩,關心用叮嚀,不用安慰。 |
| 口頭禪 | 「嗯。」「不會。」「受傷了要說,不要硬撐。」「先別動。」【取樣 SC-01、SC-03】 |
| 句長 | 中短,多數 8~20 字;平述句,很少問句,幾乎不用驚嘆。 |
| 用詞 | 現場與補救類(補、收、站位、傷口、順序);冷幽默一句(「沒有人付薪水」)。 |
| 慣用句型 | 「先…再…」;用職業類比說對方的事(「收殘局的人,常常最後才收自己」)。 |
| 禁用 | 感嘆、大聲、說教長篇;不說「我理解你的痛苦」這類空話;不調情。 |
| 怎麼稱呼別人 | 藍亭萱:「妳」【取樣】。秦亦柔:「妳」【取樣】。董振豪:「你」【推測】。麥子健:「你」【推測】。 |

## 三、董振豪

| 項目 | 內容 |
|---|---|
| 一句話 | 寡言,用事實回答,不表態。 |
| 口頭禪 | 「走過。」「……問。」「隨便妳。」「我不求妳信。」【取樣 SC-02】 |
| 句長 | 極短,多數 2~10 字;常以「……」起頭;最長的話也不超過兩個短句。 |
| 用詞 | 山、路、痕跡、認得;不用抽象詞。 |
| 慣用句型 | 被問就答一半;用「放不放心,是妳的事」把責任推回對方。好態時才多說半句。 |
| 禁用 | 長篇解釋與辯白;請求或道歉(「謝」要留到好態、極少用,才有分量);不談債與集團的細節。 |
| 怎麼稱呼別人 | 藍亭萱:「妳」【取樣】。秦亦柔:「妳」【推測】。徐培恩:「你」【推測】。麥子健:「你」【推測,保持距離,偶爾省略稱呼】。 |

## 五、麥子健(全部【推測】,現有劇本沒有他任何台詞)

| 項目 | 內容 |
|---|---|
| 一句話 | 圓滑,笑著把話繞開,永遠留退路。 |
| 口頭禪 | 「我是無所謂啦。」(表態的反面);「大家都想活著回去,不是嗎?」(用問句回問句)【推測】 |
| 句長 | 中等偏長,10~30 字;愛用問句與讓步句(「是嗎?我只是…」)。 |
| 用詞 | 客氣、禮貌、帶一點笑意:「不好意思」「哎」「這樣說就難聽了」。 |
| 慣用句型 | 被問選邊時,答「站有路的那一邊」這種答了又等於沒答的話;說真話時用「我很少說謊,只是不太回答」。 |
| 禁用 | **不說「我保證」「我站你這邊」「我信你」**—— 他絕不表態;不爆粗口;不吼叫(他不得罪人)。 |
| 怎麼稱呼別人 | 藍亭萱:「藍小姐」。秦亦柔:「秦小姐」。徐培恩:「徐先生」,好態可改「徐哥」。董振豪:「山上的」「喂」或省略稱呼(互看不起)。全為【推測】;年齡未設定,「哥」只是示意。 |
| 風險 | 唯一沒有現有台詞可比對的人;試稿 T-04、T-10 兩段先拿來驗這份聲線。 |
